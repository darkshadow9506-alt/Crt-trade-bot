# CRT Trade Bot 🐢📈

A multi-timeframe **Candlestick Range Theory (CRT)** day-trading engine in
Python — Smart-Money-Concepts analysis, a look-ahead-free backtester, prop-firm
risk guardrails, and Telegram signals.

> ربات تریدی که دقیقاً استراتژی CRT خودت رو پیاده می‌کنه: تحلیل چند تایم‌فریمی،
> بک‌تست بدون خطای آینده‌نگری، مدیریت ریسک به سبک پراپ‌فرم، و ارسال سیگنال به تلگرام.

---

## استراتژی (دقیقاً طبق چیزی که تعریف کردی)

ساختار **HTF → MTF → LTF** بعد از باز شدن سشن نیویورک:

1. **HTF (context):** بعد از باز شدن سشن، صبر می‌کنیم تا قیمت به یه نقطه مهم برسه
   (**FVG / OB / سوئیپ نقدینگی سشن‌های قبل**) و یه کندل **CRT** بزنه؛ یعنی شدوش
   نقدینگی یه طرف رنج رو بزنه و دوباره داخل رنج ببنده. این جهت و رنج معامله رو
   مشخص می‌کنه.
2. **MTF:** منتظر یه **CHoCH** هم‌جهت CRT می‌مونیم و بعد یه **پولبک به ناحیه
   فیبوناچی ۰٫۶۱۸ تا ۰٫۷۹**.
3. **LTF:** دوباره یه **CHoCH**، بعد ورود روی **iFVG** یا **CISD**.

**ریسک:** حد ضرر پشت سقف/کف کندلی که اول فیبو رو زد (+ کمی پدینگ ATR). **تارگت:**
اگه روند HTF هم‌جهت معامله باشه → **سقف/کف CRT**؛ اگه نه (کانتر-ترند) → **نقطه ۰٫۵
(equilibrium)** رنج. در حالت کانتر-ترند اگه قیمت قبل از ورود به نقطه ۰٫۵ رسیده
باشه، کلاً معامله کنسل می‌شه.

ست‌های تایم‌فریم:

| تنظیم | HTF | MTF | LTF |
|------|-----|-----|-----|
| `1D-1H-15min`   | 1D  | 1H    | 15min |
| `4H-15min-5min` | 4H  | 15min | 5min  |
| `1H-5min-1min`  | 1H  | 5min  | 1min  |

## نصب

```bash
pip install -r requirements.txt        # pandas, numpy, pyyaml, requests, pytest
cp config/config.example.yaml config/config.yaml
```

## بک‌تست (شروع از اینجا)

```bash
# دیتای نمونه ساختگی بساز (یا CSV خودت رو بذار)
python scripts/generate_sample_data.py

# اجرا روی ست تایم‌فریم انتخابی در config.yaml
python -m crt_bot.cli backtest --save

# مقایسه‌ی هر سه ست تایم‌فریم روی یک دیتا
python examples/run_backtest.py
```

فرمت CSV ورودی (نام ستون‌ها انعطاف‌پذیره): `time, open, high, low, close[, volume]`.

نمونه خروجی گزارش:

```

  Profit factor     : 2.10
  Avg R:R (planned) : 2.45
  ...
  Total return      : +6.40%
  Max drawdown      : 2.10%
========================================================
```

## معماری

```
crt_bot/
├── core/         # مدل‌ها، تایم‌فریم/resample، سشن، اندیکاتورها (ATR)
├── smc/          # تشخیص‌دهنده‌ها: structure(CHoCH/BOS), fvg/ifvg, order_block,
│                 #   liquidity sweep, crt, fib, cisd
├── strategy/     # ماشین حالت CRT (HTF→MTF→LTF) ← قلب سیستم
├── risk/         # سایزینگ + قوانین پراپ (ضرر روزانه/دراودان/تارگت)
├── backtest/     # موتور event-driven بدون look-ahead + گزارش‌گیری
├── data/         # لودر CSV و resample
├── notify/       # ارسال سیگنال تلگرام
└── cli.py        # رابط خط فرمان
```

**بدون خطای آینده‌نگری:** موتور روی کوچک‌ترین تایم‌فریم حرکت می‌کنه و در هر کندلِ
بسته‌شده فقط کندل‌هایی از هر تایم‌فریم رو به استراتژی می‌ده که تا اون لحظه واقعاً
بسته شدن. معاملات هم روی کندل‌های *بعدی* مدیریت می‌شن (پر شدن SL/TP).

## مدیریت ریسک / پراپ‌فرم

در `config.yaml` بخش `risk`:

- `risk_per_trade_pct` — درصد ریسک هر معامله (سایز پوزیشن خودکار حساب می‌شه)
- `max_daily_loss_pct` — سقف ضرر روزانه (هر روز ریست می‌شه؛ مثل FTMO)
- `max_total_drawdown_pct` — حداکثر دراودان کل (ربات متوقف می‌شه)
- `profit_target_pct` — تارگت سود فاز

## سیگنال زنده + ارسال خودکار به تلگرام

ربات بازار رو مدام چک می‌کنه و وقتی ستاپ CRT کامل شد، سیگنال (Entry/SL/TP/RR)
رو **خودکار** به تلگرام می‌فرسته. بعدش معامله رو به‌صورت مجازی دنبال می‌کنه و
موقع برخورد TP/SL هم نتیجه (مثلاً `+3.68R` یا `-1.00R`) رو پیام می‌ده.

**۱) تلگرام رو در `config.yaml` تنظیم کن:**

```yaml
notify:
  telegram:
    enabled: true
    bot_token: "123:ABC"   # از @BotFather
    chat_id: "123456789"   # آی‌دی چت یا کانال
```

**۲) منبع دیتای زنده رو انتخاب کن** (بخش `live` در `config.yaml`):

```yaml
live:
  feed: "binance"          # binance | mt5 | csv
  symbol: "BTCUSDT"        # نماد دقیق فید (بایننس: BTCUSDT ؛ MT5: XAUUSD ...)
  poll_seconds: 30
```

| فید | کاربرد | پیش‌نیاز |
|-----|--------|----------|
| `binance` | کریپتو، بدون کلید | فقط `requests` |
| `mt5`     | فارکس/طلا/ایندکس (پراپ) | `pip install MetaTrader5` + ترمینال MT5 (ویندوز/VPS) |
| `csv`     | replay آفلاین برای تست | فقط یه فایل CSV |

**۳) اجرا:**

```bash
python -m crt_bot.cli live --test-telegram     # یه پیام تستی بفرست و خارج شو
python -m crt_bot.cli live                      # حلقه زنده‌ی واقعی
python -m crt_bot.cli live --steps 200          # محدود (تست/replay)
```

هر فید فقط کندل‌های **بسته‌شده** رو می‌ده (کندل در حال شکل‌گیری حذف می‌شه) تا
سیگنال‌ها معتبر باشن. سیگنال‌های تکراری ارسال نمی‌شن و وضعیت در
`reports/live_state.json` ذخیره می‌شه تا بعد از ری‌استارت دوباره فرستاده نشه.
